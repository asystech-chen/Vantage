欢迎

欢迎使用 Vantage

先花一分钟，把外观和常用功能设好。所有选项之后都能改。

  • 基于 Firefox ESR，更新稳定
  • 默认开启跟踪保护，不收集数据
  • 设置随时可改
外观

先让它看起来顺眼

选一套自己喜欢的样子，所有选项都能随时改。

Vantage 主题
蓝系配色，工具栏、侧栏和菜单使用同一套颜色。
界面风格
Nova 是 Firefox 153 的新布局；Proton 是经典布局。
颜色模式
作用于浏览器界面和网页的默认配色。
工具栏密度
普通是默认；紧凑更省空间；触摸适合触屏设备。
想换个样子？ 主题商店里有更多配色和背景，装上就是你的。
浏览主题
启用第三方主题后，Vantage 主题会自动让位，不会覆盖你的主题。
自定义

自定义你的旅途

挑几个顺手的设置。这里只列常用的，更多在设置面板里。

多线程下载
服务器支持分段时并行下载；不支持时自动回退为单线程。
侧栏悬停弹出
鼠标移到窗口左侧边缘时，自动弹出侧栏。
Chromium 样式查找栏
标签自动休眠
内存紧张时休眠不活跃标签页，需要时再唤醒。
自动检查更新
启动后检查 Vantage 新版本，只提示，不自动安装。
AI 侧栏
在侧边栏打开 AI 聊天，支持 DeepSeek、Qwen、豆包、ChatGPT、Gemini 和 Claude。
完整列表在 设置 → Vantage。之后随时可以改。
隐私

隐私默认已经调好

Vantage 默认使用严格跟踪保护，不需要你在级别之间选择。遇到网站因为保护而显示异常时，可以只对这个网站放宽。

严格保护（默认）

拦截已知跟踪器、跨站 Cookie、指纹脚本和挖矿脚本。不需要额外设置。

自动修复轻微的网站问题
对已知会被跟踪保护弄坏的网站自动放宽，只影响这些站点，不改变全局保护级别。
DNS over HTTPS（DoH）
加密 DNS 查询。默认开启，使用国内可用节点，故障时回退系统 DNS。
单个网站出问题时，点地址栏的盾牌图标，就能只对这个网站关闭保护。
